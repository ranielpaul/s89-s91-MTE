# S8 - MTE Activity - Blog application
## Description:

A Blog sharing web application using Mongoose, Express, Vue and Node.js for the stack where users can perform crud operations on their posts, and comment on other people's blogs

# Requirements:
### Stack:
- MEVN (Mongoose, Express, Vue, Node)
- Backend is in server
- Frontend is in client

### User authentication
- register/login wit email, username, password
- password hashing

# Blog Post Management:
- users can do crud operations for blog posts
- posts should have:
    - title
    - content
    - author
    - information
    - creation date
    - comments

### All Users:
- view all post
- view a single post
- other users can add comments on blog posts
- Users who created their post can update or delete their own post

### Admin Users
- delete any posts

### Other Requirements:
- Error handling

### Current Implementation Goal:
- Backend API with CRUD
- Backend API with authentication
- .md for credentials and app description
